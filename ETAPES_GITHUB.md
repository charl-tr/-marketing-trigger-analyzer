## Après avoir créé le repository :

GitHub vous donnera des instructions. **IGNOREZ-LES** et utilisez plutôt ces commandes dans votre terminal :

```bash
cd /Users/charlesterrier/marketing-trigger-analyzer

# Initialiser git
/usr/bin/git init

# Ajouter tous les fichiers
/usr/bin/git add .

# Commit
/usr/bin/git commit -m "Initial commit: Marketing Trigger Analyzer"

# Branche main
/usr/bin/git branch -M main

# Ajouter remote (remplacez charl-tr par votre vrai username si différent)
/usr/bin/git remote add origin https://github.com/charl-tr/marketing-trigger-analyzer.git

# Pousser
/usr/bin/git push -u origin main
```

**Note** : Si GitHub vous demande de vous authentifier, utilisez un **Personal Access Token** au lieu du mot de passe.
